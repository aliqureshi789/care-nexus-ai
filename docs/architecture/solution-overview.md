# Solution Overview

CARE-NEXUS AI is a multi-agent enterprise system that helps users make workflow decisions.

## Components

### 1. User Interface
- Microsoft Teams / Copilot interface

### 2. Orchestration API
- Handles incoming requests
- Coordinates agents

### 3. Agents
- Work Context Agent
- Knowledge Agent
- Reasoning Agent
- Action Agent

### 4. Integration Layer
- SharePoint
- SQL / Fabric
- Power Automate

### 5. Output Layer
- Decision + explanation
- Next action
- Audit trail
